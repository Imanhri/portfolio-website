// ABOUT ME
Hello! I'm Iman. A Software Design (B.Sc.) student at Aschaffenburg University of Applied Sciences with a focus on Data Science and IT Security. My background combines hands-on precision with creative digital thinking.
My skills include working with Python, Java, and C++ for basic programming tasks, as well as using HTML, CSS and JavaScript to build simple web pages. I also work with Figma and Adobe Photoshop for UI ideas and visual design. In addition, I've done a team project using the Godot Engine to create an interactive learning game, where I focused on UI design and game mechanics using GDScript.
